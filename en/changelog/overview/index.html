Release notes for Stratum, starting with the first public release.

Stratum follows semantic versioning. This page records what changed in each release, newest first.

0.1.0 — first public release

The initial release introduces the local-first asset vault with automatic versioning, searchable libraries and optional local AI.

Highlights

  • Spaces. Create, open and join folders as versioned Stratum spaces.
  • Automatic versioning. A background watcher records a version on every change; preview and restore any past version.
  • Library. Grid and list views with kind, tag and date filters plus sorting.
  • Tags. Manual tags and AI-suggested tags, stored in a versioned .stratum-tags.json.
  • Search. Semantic search via nomic-embed-text with a keyword fallback.
  • Local AI tagging. Optional llava:7b vision tagging, fully offline.
  • Studio hub. Share a space across a team over a NAS or Git server, with background sync and side-by-side conflict handling.
  • Guided tour. A 13-step, 60-second interactive tour on a read-only demo space.
  • Six languages. English, Español, Русский, हिन्दी, Français and Deutsch.
