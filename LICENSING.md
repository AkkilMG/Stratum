## Metadata

Package metadata declares the OSI option for tools that require an SPDX identifier:

```text
Apache-2.0 OR LicenseRef-Stratum-Community-1.0
```

The Community License has no OSI/SPDX-standard identifier, so it is expressed with an SPDX `LicenseRef`. The `Apache-2.0` alternative is what makes Stratum a FLOSS project for registries and badges that require an OSI-approved license.
