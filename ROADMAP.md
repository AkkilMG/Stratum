# Roadmap

This is a rough, living plan — not a promise. Priorities can change based on community feedback and contributions. If you want to work on something here, please open an issue first so we can coordinate.

## Near term

- [ ] Screenshots and a short demo video in the README.
- [ ] More automated tests for the Rust backend (indexing, versioning, sync).
- [ ] Improve first-run onboarding and error messages.
- [ ] Performance work on very large vaults (100k+ assets).
- [ ] Packaging: signed Windows/macOS builds and a Linux AppImage with auto-update.

## Medium term

- [ ] Plugin/extension points so studios can add their own importers and metadata.
- [ ] Better team conflict resolution UI.
- [ ] Asset collections and smart folders.
- [ ] Optional additional AI backends beyond Ollama.
- [ ] Accessibility pass and keyboard-first workflows.

## Ideas / under discussion

- [ ] Web-based read-only viewer for a vault.
- [ ] Perforce/other VCS backends.
- [ ] Asset dependency graphs (which models use which textures).
- [ ] More languages.

## Done

- [x] Local-first versioned asset vault (v0.1.0).
- [x] Local AI tagging and semantic search (v0.1.0).
- [x] Six languages (v0.1.0).
- [x] Free and open source under the Stratum Community License.

Want to suggest something? [Open an issue](https://github.com/AkkilMG/Stratum/issues/new/choose).
