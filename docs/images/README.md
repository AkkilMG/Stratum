# Screenshots

UI captures for the repository [README](../README.md) and documentation live here.

The README reserves a spot for them; until real captures are committed, the built-in
**60-second tour** in the app covers the same ground against a safe practice space.

## Naming

Use lowercase, dash-separated names that describe the screen, for example:

- `library.png` — Library with visual previews
- `asset-details.png` — asset details, tags and versions
- `history-sync.png` — history and studio sync
- `settings.png` — settings and local AI status

## Guidelines

- Capture the real app at a consistent window size; use the light theme for the primary
  shot and the dark theme where it reads better.
- Prefer PNG for UI; keep each file reasonably small so the README stays fast.
- No real studio assets in screenshots — use the tour's sample files or placeholder art.
- Reference them from the README with relative paths (`./docs/images/...`) and a useful
  `alt` text.
