What is Stratum

Stratum is a local-first, versioned, searchable asset vault for game studios.

Stratum is a desktop app that keeps every asset a game studio produces — textures, source files, maps, 3D models and audio — versioned, searchable and safe, even when fully offline. Your assets never leave your own machines.

Why Stratum

Game projects generate thousands of files. They get renamed, overwritten, duplicated across drives, and the one person who knew where the hero texture lived leaves the studio. Stratum gives a team one calm place to keep everything with a memory:

  • Automatic versioning. Every save becomes a restorable version — no commits, branches or commands for the artist to learn.
  • Search by meaning. Ask for "red desert sector map" and find it, even if nothing is named that way.
  • Offline-first. It is just a folder on disk. No account, no upload, no telemetry, no lock-in.
  • Built for teams. Share a space over your own LAN, NAS or any Git server. Conflicts are kept, never silently lost.

How it works

Stratum is deliberately boring under the hood, which is what makes it trustworthy:

  • A space is a folder. Stratum adds a hidden Git repository to the folder you pick. The files themselves are ordinary files you can open in any tool.
  • Versions are Git commits. A file watcher notices changes and records a version automatically. You can preview any past version and restore it.
  • Search is local AI plus a keyword fallback. Optional Ollama models describe images and build embeddings; without them, keyword search still works.
  • Team sync is a shared Git remote. Point two or more machines at the same bare repository on a NAS or Git server and they stay in step.

Note

Stratum shells out to the standard git command-line tool. You can always open the folder with your own Git tools, so there is no proprietary format to escape from.

Who it is for

  • Solo developers who want version history without becoming Git experts.
  • Small studios sharing a NAS who need everyone to see the same art.
  • Technical artists and pipeline engineers who want a local, scriptable vault.

What it is not

  • It is not a cloud drive. There is no Stratum account or hosted service.
  • It is not a DCC replacement — Stratum organises assets, it does not edit them.
  • It is not a build pipeline or task tracker.
