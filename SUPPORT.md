## Getting help

| I want to… | Go to |
| --- | --- |
| Report a bug | [Open a bug report](https://github.com/AkkilMG/Stratum/issues/new/choose) |
| Request a feature | [Open a feature request](https://github.com/AkkilMG/Stratum/issues/new/choose) |
| Ask a question | [GitHub Issues](https://github.com/AkkilMG/Stratum/issues) or contact@arkynox.com |
| Report a security issue | See [SECURITY.md](SECURITY.md) — please report privately |
| Contribute | See [CONTRIBUTING.md](CONTRIBUTING.md) |

When reporting a bug, please include your OS, the Stratum version, and the diagnostics from **Settings → Help & about → Copy diagnostics**. That makes problems much faster to solve.

Stratum is a community project maintained by volunteers. Please be patient and kind.
