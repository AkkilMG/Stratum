# AGENTS.md

Guidance for AI coding agents (and humans) working in this repository.

## Project

Stratum is a local-first, versioned, searchable asset vault for game studios. It is a Tauri 2 desktop app: a React + TypeScript frontend (`src/`) and a Rust backend (`src-tauri/`).

## Commands

Run from the repository root.

| Task | Command |
| --- | --- |
| Install deps | `npm install` |
| Run the app (dev) | `npm run tauri dev` |
| Build frontend | `npm run build` |
| Type-check | `npm run typecheck` |
| Lint | `npm run lint` |
| Lint (fix) | `npm run lint:fix` |
| Format | `npm run format` |
| Check formatting | `npm run format:check` |
| Rust lint | `cargo clippy --manifest-path src-tauri/Cargo.toml` |
| Regenerate license bundle | `npm run licenses` |
| Build installers | `npm run tauri build` |

## Conventions

- TypeScript strict mode is on; do not introduce `any` unless unavoidable.
- Do not add comments unless they explain something non-obvious.
- Follow the style of the file you are editing; match existing patterns and naming.
- Prefer the existing helpers and utilities over new dependencies.

## i18n rules (important)

- `src/i18n/locales/en.ts` is the source of truth. The other locale files are type-checked against it: **every key must exist in all six languages** (`en`, `es`, `ru`, `hi`, `fr`, `de`) or the build fails.
- Keep `{placeholders}` identical across languages.
- Do not translate the product names "Stratum" or "Arkynox".
- Backend errors are returned as codes (`E:code[:detail]`) and translated in the UI.

## Do not edit

- `src/licenses.json` and `THIRD_PARTY_NOTICES.txt` are generated by `npm run licenses`.
- `src-tauri/target/`, `dist/`, `node_modules/` are build output and ignored.

## Before opening a change

Run `npm run typecheck`, `npm run lint` and `npm run build`, and make sure they pass. See [CONTRIBUTING.md](CONTRIBUTING.md).
