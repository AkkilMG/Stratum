Installation

Install the Stratum desktop app on Windows, macOS, or Linux.

Prebuilt installers are published on GitHub Releases for Windows, macOS and Linux. Pick your platform below and you are a few clicks away from your first space.

Requirements

ComponentRequired?Notes
GitYesStratum shells out to the git CLI for all versioning.
OllamaNoEnables local AI tagging + semantic search; keyword search works without it.

Warning

Stratum needs Git installed and on your PATH. On first launch the setup wizard checks for it and tells you if something is missing.

Download

Grab the latest installer from the Stratum Releases page. Pick the file that matches your operating system:

PlatformFiles
Windows.exe (NSIS installer) or .msi
macOS.dmg or .app.tar.gz
Linux.AppImage, .deb or .rpm

Windows

  1. Download Stratum_x.y.z_x64-setup.exe (or the .msi).
  2. Run the installer and follow the prompts.
  3. Launch Stratum from the Start menu.

If SmartScreen warns about an unknown publisher, choose More info → Run anyway. Stratum is unsigned by default; checksums and a software bill of materials are attached to each release.

macOS

  1. Download the .dmg for your chip (Apple silicon or Intel).
  2. Open the disk image and drag Stratum into Applications.
  3. The first launch may be blocked by Gatekeeper. Right-click the app and choose Open, then confirm.

Linux

shell
chmod +x Stratum_x.y.z_amd64.AppImage
./Stratum_x.y.z_amd64.AppImage

Note

The .deb and .rpm packages declare a dependency on git where appropriate. On minimal systems, install Git first.

Optional Ollama models

To enable AI tagging and semantic search, install Ollama and pull the two models. You can also do this from inside Stratum (Settings → Local AI).

shell
ollama pull llava:7b
ollama pull nomic-embed-text

Tip

Both models run locally and never send your assets anywhere. They are optional — Stratum is fully usable without them.

Verify the install

Launch Stratum and continue to First launch. The setup wizard's system-check step confirms that Git (and optionally Ollama) are detected correctly.

Note

Want to build Stratum yourself or contribute? See the For developers section for the full toolchain, build steps and contribution guide.
