Error codes

What Stratum's E: and M: error codes mean, and how to resolve them.

When something goes wrong, Stratum shows a short code you can look up or quote in a bug report. Codes come in two families.

Code format

  • E:… — an environment problem: something missing or misconfigured on the machine (Git, a path, permissions).
  • M:… — a managed operation problem: Stratum tried an action (sync, import, restore) and it didn't complete.

E: — environment

CodeMeaningFix
E:GIT_NOT_FOUNDThe git command-line tool isn't on PATH.Install Git and restart Stratum.
E:GIT_TOO_OLDGit is below the minimum supported version.Update Git to a current release.
E:PATH_UNREACHABLEA folder or share can't be reached.Reconnect the drive / remap the NAS path.
E:PERMISSION_DENIEDStratum can't read or write a path.Check folder permissions or pick another folder.
E:NOT_A_REPOThe folder isn't a Stratum space and couldn't be initialised.Choose an empty or writable folder, then retry.

M: — operations

CodeMeaningFix
M:SYNC_FAILEDA push or pull didn't complete.Check connectivity to the remote and try Sync now.
M:PUSH_REJECTEDThe remote had newer changes.Sync again — Stratum will pull, then push.
M:CLONE_FAILEDJoining a studio space failed.Verify the remote URL and that you have read access.
M:IMPORT_FAILEDA file couldn't be copied into the space.Check free space and permissions, then retry.
M:RESTORE_FAILEDWriting an old version back failed.Ensure the file isn't locked by another app.
M:INDEX_FAILEDThe index or thumbnails couldn't be rebuilt.Try Settings → This space → Rebuild index.
M:MODEL_DOWNLOAD_FAILEDAn Ollama model didn't download.Check that Ollama is running, then retry the download.

Tip

Most M: errors are transient and succeed on a retry once the underlying cause (network, file lock, running service) is resolved.

Reporting a problem

If a code persists, open an issue on GitHub with the code and what you were doing. Include the Stratum version from Settings → Help & about. See also Troubleshooting & FAQ.

Note

Error messages never contain asset contents. Stratum doesn't upload logs anywhere — you decide what to share.
