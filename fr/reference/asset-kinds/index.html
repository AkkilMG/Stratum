Asset kinds & extensions

How Stratum classifies files, which extensions map to each kind, and preview support.

Stratum assigns every asset a kind based on its extension. The kind drives icons, previews and library filters.

The kinds

KindPurpose
ImageRaster artwork and photos.
VectorScalable vector graphics.
SourceEditable working files from DCC and design tools.
Model3D meshes and scenes.
AudioSound effects, music and voice.
OtherAnything that doesn't match a known kind.

Extension map

KindExtensions
Imagepng, jpg, jpeg, gif, webp, bmp, tif, tiff, exr, hdr, tga, dds
Vectorsvg
Sourcepsd, psb, ai, xcf, blend, ma, mb, c4d, max, fig, sketch, aes
Modelfbx, obj, glb, gltf, usd, usda, usdc, usdz, stl, dae, 3ds
Audiowav, mp3, ogg, oga, flac, aac, m4a, aiff
Othereverything else

Note

The list is matched case-insensitively, so PNG and png classify the same way.

Unknown files

Files with unrecognised extensions are still versioned, indexed and searchable — they're just shown with a generic icon and classified as Other. Nothing is ever skipped because Stratum didn't recognise it.

Tip

If a file type you use often shows as Other, it's still fully tracked. Kind is a convenience for filtering, not a limit on what Stratum stores.
