Guide d'utilisation

Tags

Add manual tags, accept AI-suggested tags, and understand the shared tags file.

Tags make assets findable. Add them yourself, accept suggestions from local AI, or both — and they travel with your space.

Adding tags

Open an asset's detail drawer and type in the tag field. Press Enter to add the tag, or Enter on an existing tag to reuse it. Tags are normalised to lowercase and trimmed, so Hero and hero don't become two tags.

You can also tag a whole selection at once from the library: select assets, then Add tags.

AI-suggested tags

When local AI is enabled, Stratum asks the llava:7b model to look at image assets and propose descriptive tags. Suggestions appear in the drawer for you to accept or dismiss — Stratum never applies AI tags silently.

Note

AI tagging only runs on images. It is entirely local: the image is handed to your own Ollama instance and never uploaded.

Managing tags

  • Remove a tag by clicking the × on its chip.
  • Rename a tag app-wide from the tag it produces in the library filter panel.
  • Deleted tags are removed from every asset that carried them.

The tags file

All tags for a space live in one human-readable file at the space root:.stratum-tags.json. Because it's a normal file, tags are versioned by Git and sync to teammates automatically.

json.stratum-tags.json
{
  "version": 1,
  "tags": {
    "Imported/2026-01-01/hero_armor.psd": ["character", "armor", "hero"],
    "Imported/2026-01-01/sector_map.png": ["level-03", "desert", "map"]
  }
}

Tip

You can edit this file with any text editor if you prefer. Stratum reloads it on change.
