Asset details & versions

Open an asset, preview its current and past versions, read metadata, and restore.

Click any asset to open a detail drawer showing its preview, metadata, tags and full version history — with the ability to restore any past version.

The detail drawer

The drawer slides in from the right and keeps the library visible behind it, so you can move between assets without losing your place. It shows:

  • A large preview (thumbnail or representative icon).
  • The file name, kind, size and last modified time.
  • Tags (editable in place).
  • The version list, newest first.

Current vs. past

For assets with more than one version, Stratum shows Current alongside the version you select. This side-by-side view makes it easy to see what changed before you decide to restore.

Tip

Select a version on the left of the history rail and the preview switches to it immediately — no extra clicks.

Metadata

FieldMeaning
NameFile name inside the space.
KindClassified asset type (image, model, audio…).
SizeSize of the current version on disk.
ModifiedWhen the latest version was recorded.
PathLocation relative to the space root.
HashContent hash used to detect changes.

Version history

Every version is a point in time, with a timestamp and the author (your display name, or a teammate's after sync). Stratum never deletes versions when you edit a file; it adds a new one.

Restoring a version

  1. Open the asset and select the version you want in the history list.
  2. Choose Restore this version.
  3. Stratum writes the old contents back as a new version on top of history.

Warning

Restoring does not erase anything. The version you restored from — and everything after it — remains in the history, so a restore is always reversible.
